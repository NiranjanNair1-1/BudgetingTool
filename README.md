# BudgetingTool

Niranjan User Stories:

Story 1: As a user, I want to add an expense with date, amount, category and description, so that I can track my spending.

Story 2: As a user, I want to add income (e.g. salary), so that I can see the money coming in.

Story 3: As a user, I want a clear message and another try when I type something invalid, so that the app never crashes.

Andras User Stories:



Alpha User Stories:
User Story 1: As a user, I want to choose a category from a fixed list and see how much I spent per category, so that I know where my money goes.

User Story 2: As a user, I want to set a monthly budget per category and get a warning when I go over it, so that I don't overspend.

User Story 3: As a user, I want to set a savings goal and see my progress, so that I stay motivated.


Stefano User Stories:

Story 1: As a user, I want to see all my transactions, sorted by date, so that I have an overview.

Story 2: As a user, I want to filter the list (only expenses, only income, one category), so that I find things quickly.

Story 3: As a user, I want a dashboard with income, expenses and balance for a month I choose, so that I know where I stand.
