# BudgetingTool

Niranjan User Stories:

  US-01: As a user, I want to add an expense with amount so that I can track my spending.

  US-02: As a user, I want to add income (e.g. salary), so that I can see the money coming in.

  US-03: As a user, I want to add an expense with category and description, so that I can track my spending.



Andras User Stories:

  US-04: As a user, I want to add an expense with a date so that I can track my spending.

  US-05: As a user, I want to edit a wrong entry, so that my data stays correct.

  US-06: As a user, I want to delete a wrong entry, so that my data stays correct.




Alpha User Stories:

  US-07: As a user, I want to choose a category from a fixed list and see how much I spent per category, so that I know where my money goes.
  
  US-08: As a user, I want to set a monthly budget per category and get a warning when I go over it, so that I don't overspend.

  US-09: As a user, I want to set a savings goal and see my progress, so that I stay motivated.




Stefano User Stories:

  US-10: As a user, I want to see all my transactions, sorted by date, so that I have an overview.

  US-11: As a user, I want to filter the list (only expenses, only income, one category), so that I find things quickly.

  US-12: As a user, I want a dashboard with income, expenses and balance for a month I choose, so that I know where I stand.
