# BudgetingTool

Niranjan User Stories:

Story 1: As a user, I want to add an expense with date, amount, category and description, so that I can track my spending.

Story 2: As a user, I want to add income (e.g. salary), so that I can see the money coming in.

Story 3: As a user, I want a clear message and another try when I type something invalid, so that the app never crashes.
